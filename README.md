# 🌐 Personal Portfolio

A modern responsive personal portfolio website built using HTML, CSS, and JavaScript.  
It showcases my projects, skills, experience, and includes a working contact form powered by EmailJS.

---

## 🚀 Features

- Responsive modern UI
- Smooth scroll animations
- Project showcase section
- Skills and tools overview
- Working contact form (EmailJS integration)
- Clean footer with social links

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- EmailJS
